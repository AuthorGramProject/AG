# Nagram Extera 1.0.0

## What's New

### Rebranding
- App officially rebranded from **Nagram XF** to **Nagram Extera**
- Updated app name across all supported languages

### Na-Settings
- Renamed from "N-Settings" to **Na-Settings** across all localizations
- Updated all related dialog messages and hints

### Navigation
- **Customize Navigation** — renamed from "Customize Bottom Tabs"
- **NavBar Mode** — renamed from "Bottom Bar Display Mode"

### AyuGram Features
- Renamed "AyuMoments" section to **AyuGram Features**

### About Screen
- Restructured with Nagram Extera channels at the top
- Added community group link (@NagramExteraCommunity)
- Added upstream credits: NagramXF, NagramX, Nagram, AyuGram, exteraGram
- Added this Changelog entry

### Recent Chats Sidebar
- Panel now matches the Telegram action bar color scheme
- Added "Disable Show Recent Chats" option in settings menu

### Build & Versioning
- Fully automatic versioning — no more manual version bumps
- Version code derived from git commit count
- Multi-ABI build support (arm64-v8a, armeabi-v7a, x86_64, universal)
- Configuration-cache-safe Gradle build
